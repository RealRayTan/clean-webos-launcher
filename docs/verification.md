# 验证记录

此记录区分实机观察、本地模拟和未验证范围。日期为 2026-10-21。原始记录对应 1.0.7，后续验证按版本追加。

## 实机已确认

| 项目 | 证据范围 |
|---|---|
| 中文显示 | 电视实际截图中字体、问候语、日期和菜单正常 |
| 短按与长按 Home | 用户用实体遥控器确认短按没有原厂首页闪回，约一秒长按进入原厂首页 |
| 应用与菜单 | 通过遥控协议从桌面打开应用、选择 HDMI，并在电视截图中确认原生设置面板 |
| 新桌面待机恢复 | 1.0.4 的新恢复模块，从新桌面关机后唤醒，前台为新桌面；一次 |
| HDMI 待机恢复 | 同一模块，从 HDMI 关机后唤醒，前台仍为 HDMI；一次 |
| 1.0.7 在线状态 | 更新后助手为 root、enabled、active，原生模块映射与租约存在；原有内容应用前台未变 |
| 安装文件 | 1.0.7 的十个关键文件与本地源码或固定依赖摘要一致 |

1.0.6 修正桌面重新显示时遗留的确认键状态。1.0.7 修正异常路径后，没有重复开关机或物理按键检查。

## 本地已确认

1.0.7 的 `node --test tests/*.cjs` 记录为 15 项通过。七项覆盖按键策略，四项覆盖桌面与 HDMI 的正常恢复，四项覆盖本轮可靠性修复。

可靠性检查包含：回调丢失和跨休眠迟到、一次保存失败后的重试、真实本地 UNIX socket 进程异常退出后的残留回收、助手状态失联时仍能持久停用。这些是本地模拟或临时本地进程，不是对电视做故障注入。

公开仓库的连接工具已移除设备专用参数。参数化安装入口只做了本地语法检查，没有为发布仓库重新安装电视。GitHub Actions 只做源码检查，不把 CI 通过等同于实机验收。

## 尚未确认

- 当前界面恢复逻辑的完整冷启动。早期 1.0.3 的冷启动成功不能覆盖新逻辑。
- 其他电视型号、固件或 64 位输入进程。
- 电脑视频信号下的 HDR、刷新率和显示延迟；本次只确认输入源路由。
- 助手进程崩溃后自动重启。当前仅支持重新启动后回收残留 socket。
- 突然断电时最新状态的磁盘耐久性。

后续验证按每种行为一次执行，不重复三次。

## 1.0.8 返回来源验证

使用哔哩哔哩实际遥控返回及退出确认，新桌面入口与原厂首页入口各验证一次，退出后分别回到新桌面和原厂首页，均通过；随后恢复操作前的 HDMI。安装文件的十一项校验一致，未开关机。新返回策略的本地检查同时覆盖主动长按 Home、休眠、超时回复与输入源切换，不把它们替代为新的物理验收。其他应用未逐项实测。README 中的截图仍为 1.0.7，版本标注保持不变。

## 1.0.9 应用管理验证

2026-10-21 安装到同一台 LG C5。电视端接口读到新安装的 Alcyone，所有可显示应用均有图标。使用遥控协议进入管理面板，手动刷新一次，隐藏 Apps；关闭并重新打开桌面后，面板仍显示“已隐藏”。随后恢复 Apps，并确认列表包含 Alcyone。各操作一次，恢复操作前的 HDMI。没有开关机，也没有重新验证此前已通过的 Home 长短按。

全部图标隐藏时的空状态、存储写入失败和其他型号尚无实机验收。VPN 属于单独安装的第三方应用，本仓库不包含它的订阅、运行配置或本次 DNS 兼容补丁。

## 1.1.0 磁贴版验证

同日更新到同一台 LG C5，安装前保留应用和服务备份。实机截图确认中文、山谷壁纸、浅色磁贴边框和“VPN 已连接”标签。电视端接口返回 Alcyone 连接状态，前端只取得布尔值。

通过遥控协议各操作一次：电脑磁贴切到 HDMI 4，哔哩哔哩磁贴打开对应应用，退出确认后返回新桌面，编辑入口显示实际安装的十个应用。结束时回到新桌面。没有重复开关机或实体 Home 长短按验证，三个相关后台模块未改动。

Chrome 中确认增减应用、刷新后保留选择、方向键排序及保存、浅色与深色外观。自动主题的 07:00 和 19:00 边界用本地函数检查。随后实机自然跨过 19:00，未手动切换主题，截图确认从浅色变为深色。07:00 的自然切换尚未实机等待。原有十六项后台行为检查通过。浏览器检查不代替电视持久保存或实体遥控长按验收。新素材和设备适配文件一并纳入安装摘要核对。

README 的磁贴图为 1.1.0 实机截图，早期对比图仍标注 1.0.7。公开截图只展示界面，不含配对或节点认证信息。

## 1.1.1 界面精简

同日更新到 LG C5，移除首页应用、电脑卡片和底部四个工具入口的装饰箭头，以及首页按键说明。编辑和排序功能保留。Chrome 与实机截图确认显示，四个改动文件的安装摘要与最终源文件一致。没有开关机，也没有重复后台行为测试。README 当前截图更新为 1.1.1，1.1.0 的明暗切换图保留在图片目录和版本历史中。

另外对已安装的 Alcyone 4.2.2 和 YouTube AdFree 0.5.3 各做了一次返回场景观察：Alcyone 主界面按返回后仍在主界面；YouTube 返回侧栏首页后，再按返回仍停留在应用内。原生按键配置仅接管 Home，返回键没有自定义绑定。此观察确认当前版本的表现，不推断其他版本、其他页面或实体遥控长按行为，也没有修改第三方应用。
